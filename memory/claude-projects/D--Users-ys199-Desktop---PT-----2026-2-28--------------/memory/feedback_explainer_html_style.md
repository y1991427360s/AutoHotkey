给用户做**讲解 / 教学 / 原理可视化**类 HTML（如电力工程的 PT/CT 原理、互感器、继保等概念解释）时，默认采用以下风格，不要用深色主题：

- **整体亮色**：白底 + 浅蓝灰背景（`--bg:#f6f8fc`、`--panel:#fff`、`--line:#dde3ee`），淡阴影 `box-shadow:0 4px 14px rgba(20,30,60,.06)`
- **配色语义化**：主体两类用对比色（如 PT 蓝 `#1f6feb` / CT 橙 `#e0531f`），状态用 ok 绿 / warn 黄 / bad 红
- **卡片网格布局**：CSS Grid 双列，移动端折单列，圆角 14px
- **内联 SVG 手绘电路图**：用 `<line>` `<path>` `<circle>` 直接画，不引外部库
- **故障/正常态切换按钮**：按钮 onclick 用几行 JS 改 SVG 元素的 `display` 和 `fill`，提供"❌ 故障演示"+ "✅ 正常运行"两态对比，并联动一个 `.status` 状态条
- **不依赖任何前端框架**，纯 HTML+CSS+原生 JS 单文件，双击可开

**Why:** 2026-05-28 给用户做 PT/CT 安全规则讲解 HTML，第一稿用了深色（`#0f1117` 底），用户要求"改成亮色风格"，改完后用户主动评价"这个风格还挺好看的"。这是一次明确的非即时确认 —— 亮色卡片+SVG 是对的方向。

**How to apply:** 用户下次让做"讲讲 X 是什么、写个 HTML 让我理解"这类教学/可视化文档时直接用亮色方案，不要再先出深色。如果是"做个炫酷的 demo / 数据大屏 / 后台管理界面"等场景属性不同，本规则不适用。
