为该用户写辩论稿、说服性文稿或研究类内容时，默认遵守两条：(1) 语言可以华丽有气势，但要**克制、口语可朗读**，不要辞藻堆砌；(2) 所有数据与案例**必须真实可核验、给得出来源，绝不凭空编造**；查不到可靠来源的量化说法要主动剔除，并在文末附「出处清单」。

**Why:** 用户明确说过"不要凭空生成"、要"真实的论据"；首版改写过度华丽被当面指出"太华丽了"。

**How to apply:** 需要论据时，先跑"联网检索 + 独立事实核查（查不到来源即判 uncertain、不放行）"再动笔；每个分论点先焊一条硬证据再展开。可复用方法与一个完整范例已存进用户知识库 `D:\Syncthing\Oracle-Sync\知识库\`（`工具/AI多智能体写辩论稿方法.md`、`其他/辩论稿-AIDC能源建设全预装vs土预并存.md`），写同类文稿前可先去那里查。
